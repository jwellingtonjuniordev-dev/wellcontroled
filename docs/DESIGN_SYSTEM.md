# Design System — WellControled

## Identidade

**Marca:** WellControled  
**Mensagem:** Planeie · Controle · Realize  
**Linguagem visual:** fintech moderna, fundos azul-marinho, verde-esmeralda para ações principais e superfícies com contraste.

## Tokens propostos

| Token | Light | Dark |
|---|---|---|
| Background | `#F8FAFC` | `#0B1120` |
| Surface | `#FFFFFF` | `#0F172A` |
| Surface secondary | `#F1F5F9` | `#162033` |
| Text | `#0F172A` | `#F8FAFC` |
| Muted text | `#64748B` | `#94A3B8` |
| Primary | `#059669` | `#10B981` |
| Primary hover | `#047857` | `#34D399` |
| Border | `#E2E8F0` | `#263449` |

Estes são os tokens de referência da identidade visual; o ficheiro `app/globals.css` é a fonte efetiva dos estilos atualmente renderizados.

## Semântica

- Receitas: verde.
- Despesas: rosa/vermelho.
- Poupança: azul.
- Avisos: âmbar.

A cor nunca deve ser o único sinal de estado: usar rótulos e ícones. Garantir contraste adequado, estados de foco visíveis e navegação por teclado.

## Componentes esperados

- Campo de formulário, botão primário, botão secundário.
- Cartão de métrica, tabela/lista de transações, etiqueta de categoria.
- Sidebar/menus responsivos e seletor Light/Dark.
- Estados de erro, vazio e carregamento.
