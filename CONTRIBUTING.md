# Contribuir para o WellControled

Obrigado pelo interesse no projeto. Este repositório é também um exercício prático de desenvolvimento web.

## Ambiente

```bash
npm install
npm run dev
npm run build
```

## Fluxo de trabalho

1. Abra uma issue descrevendo a alteração (quando apropriado).
2. Crie uma branch a partir de `main`: `feature/nome-da-funcionalidade` ou `fix/descricao-do-erro`.
3. Faça commits pequenos e descritivos, por exemplo: `feat: add transaction filters`.
4. Valide o comportamento responsivo, o tema claro e o escuro.
5. Abra um pull request com descrição, testes realizados e capturas de ecrã quando aplicável.

## Boas práticas

- Utilize TypeScript e evite `any` sem justificação.
- Não inclua credenciais, dados pessoais ou capturas de contas financeiras reais.
- Mantenha componentes pequenos e com responsabilidades bem definidas.
- Documente alterações no comportamento ou nas APIs.
- Evite apresentar funcionalidades planeadas como já concluídas.

## Checklist de pull request

- [ ] A aplicação compila (`npm run build`).
- [ ] Funciona no ecrã pequeno e no desktop.
- [ ] Testei Light e Dark Mode.
- [ ] Não incluí segredos ou dados reais.
- [ ] Atualizei a documentação pertinente.
